# interactive-lamp-login
This a interactive login which looks like a dark room until you pull the string on the lamp to illuminate the room and see the login card. You can even turn the lamp back off...

# 🛋️ Interactive Lamp Login

A cinematic login experience inspired by interactive web animations.

## ✨ Features

- 🪢 Interactive lamp pull-string
- 💡 Cinematic lighting reveal
- ✨ Ambient particles
- 🪟 Glassmorphism login UI
- 🎬 Framer Motion animations
- 🎯 Lucide React icons
- 📱 Responsive design

## 🛠️ Tech Stack

- React
- Vite
- Framer Motion
- Lucide React
